# Bodega Despachos - Diseño y Consultas SQL

Este repositorio contiene los scripts para el diseño e implementación de una base de datos relacional orientada a despachos y despachadores de compras por internet. Fue desarrollado para la materia de **Bases de Datos / Seguridad en Bases de Datos** en el programa de **Técnico en Servicios de Seguridad Informática**.

## Lógica y consultas aplicadas
* **Estructura relacional**: Tablas creadas con claves primarias y foráneas para relacionar clientes, productos, transportadores y despachos.
* **Consultas e inserciones**: Consultas SQL avanzadas para calcular fechas de despachos históricos y manipulación de texto con funciones nativas.
* **Seguridad de accesos**: Scripts de ejemplo para la creación de usuarios en la base de datos y la concesión de permisos de lectura.

## Archivos del repositorio
* `database/schema.sql`: Creación del esquema de tablas y carga inicial de registros.
* `database/queries.sql`: Consultas de datos y scripts de privilegios de usuario.
